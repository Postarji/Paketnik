# Computer Vision Project

## Overview
This project is a collaborative effort by three second-year Computer Science students at the Faculty of Maribor. Developed in Python using Visual Studio Code, it focuses on implementing a computer vision solution involving data capture, data augmentation, and model training.

## Prerequisites
- Python 3.8 or higher
- Visual Studio Code
- pip (Python package manager)

## Installation
1. Clone this repository to your local machine.
2. Navigate to the project directory in your terminal.
3. Install the required dependencies by running:
   ```bash
   pip install -r requirements.txt
   ```

## Project Structure
- `main.py`: The main script that orchestrates the project by calling functions for data capture, data augmentation, and model training.
- `data_capture.py`: Handles data collection and preprocessing.
- `data_augmentation.py`: Implements data augmentation techniques to enhance the dataset.
- `model_training.py`: Contains the code for training the computer vision model.

## Usage
1. Ensure all dependencies are installed (see Installation section).
2. Run the main program:
   ```bash
   python main.py
   ```
3. The `main.py` script will execute the pipeline, combining data capture, augmentation, and model training.
